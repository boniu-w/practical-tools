# Avalonia 迁移记录

当前架构、里程碑和后续验收条件统一维护在[迁移计划](../迁移到Avalonia跨平台改造计划书.md)。本文件保留实施历史；后面的“第一步”描述当时状态，不代表当前仍未接入数据库和激活。

## 2026-10-30：播放解码模式调整

默认通过 MediaPlayer.EnableHardwareDecoding 允许自动硬件解码，移除引擎层强制关闭参数。预览增加“禁用硬件加速”兼容选项；切换时停止播放，在下一次播放时应用，无需重新解密，选择仅在控件生命周期内保留。原先引擎参数并不足以表达 MediaPlayer 的播放配置，本次统一由播放器配置控制。

验证：Avalonia 32/32，通过真实播放测试覆盖切换停止、软件模式重新播放、恢复自动模式及关闭释放；Windows 原生 AVI/WMV/WAV/AAC 双轮冒烟通过。此验证不保证每个样本实际使用 GPU，也不替代 Mac/Linux 实机验收。
