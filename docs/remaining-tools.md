## 文件整理

- 仅选定目录的直接子文件，后缀大小写不敏感；最多 10000 项。后缀仅允许字母、数字、短横线和下划线，不允许路径片段。
- 预览不改变文件。修改目录/后缀会作废预览。确认框列出每一条源路径及目标路径。
- 执行前复核源文件长度、时间和 SHA-256；链接/重解析路径拒绝，不覆盖任何目标。逐项失败继续，其余成功移动保留。取消在读块和移动边界检查。
- 不自动回滚已完成的移动，不同步数据库中既有路径快照；文件记录不是实时文件系统索引。失败只显示前 20 条，显示失败总数。
- 使用系统 File.Move 与路径检查，没有跨进程文件系统事务；同一用户并发替换目录的竞态及各平台权限需实机验收。测试仅移动临时夹具。

## 记录管理

- 文件记录添加时读取文件元数据/MD5，不移动或改写原文件；同路径跳过。单次最多 1000 个文件，列表最多 1000 条，搜索可缩小范围。
- 文件记录只编辑类别，删除需要确认且仅删除数据库记录。已迁移但当前机器不存在的旧路径仍可查看/移除记录。
- 黑名单是人工备注记录，不参与扫描过滤或自动删除。平台、作者必填，文本字段沿用 255 字符限制，作品日期用 yyyy-MM-dd。
- 每次数据库操作使用独立作用域，服务内串行写入，更新保留创建时间等未编辑字段；删除仅针对选中 ID。
- 通用数据备份/转移继续使用现有加密迁移包，不另建不加密的记录导出通道。

## 验证

Core 新增 8 项：非递归与不覆盖、预览只读、同时间同大小内容变化、取消、伪造目标、非法后缀、文件记录持久化/去重/修改/删除不伤源文件、黑名单 CRUD/无效输入保护。UI 新增 2 项：黑名单表单保存和文件整理预览作废。原生视频冒烟继续保留独立执行，平台验收清单仍在主计划第七步。
