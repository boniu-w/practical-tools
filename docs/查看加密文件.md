# 查看加密文件

入口：主窗口 → 加密文件 → 查看加密文件（位于“我要生成一个密钥对”之后）。

1. 在下方密钥表中勾选一个包含私钥的密钥；只有他人公钥时无法解密。
2. 选择 `.gpg` 文件，点击“查看加密文件”。文件加密成功后会自动填入此页。
3. 点击“放大”可收起密钥表，也可以拖动分隔线调整查看区域。
4. “关闭预览”、切换页签或退出程序会释放预览并清理临时解密文件。

支持 UTF-8、带 BOM 的 Unicode、GB18030/GBK 文本，常见图片，PDF，Word `.docx`，Excel `.xlsx`，以及浏览器支持的音视频编码。PDF 可翻页和缩放；视频提供原生播放、暂停、进度及音量控制。

Word 展示正文和表格，不还原完整分页、嵌入图片及复杂版式。Excel 展示各工作表的单元格内容和已缓存的公式结果，不执行宏或重算公式。旧版 `.doc`、`.xls` 需先转换为 `.docx`、`.xlsx`。大文本文档和工作簿有预览上限，界面会提示截断。

PDF 和音视频使用 Microsoft Edge WebView2 Runtime；缺少时界面会提示安装。能否播放某个视频取决于实际编码，不能只凭扩展名判断。所有内容在本地加载。

解密采用流式读写并校验 PGP 完整性，不把整个视频加载到内存。每次查看使用独立临时目录；失败或取消同样清理，异常退出的遗留目录在下次启动时再次清理。

验证命令：

```powershell
dotnet build PracticalTools/PracticalTools.csproj
dotnet test TestProject/TestProject.csproj --filter FullyQualifiedName~DecryptionPreview
```

UI 测试使用独立内存数据库和离屏窗口，不访问实际密钥库；覆盖内嵌文本、PDF、视频播放和切换/离开后的临时文件清理，需要 WebView2 Runtime。
