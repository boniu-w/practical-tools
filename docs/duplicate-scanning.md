# 重复文件扫描与移除

## 使用

打开“重复扫描”，选择多个本地目录，或在路径框中每行填写一个目录。扩展名可填 `.txt;.pdf`、`txt,pdf` 或 `*.txt`，留空为全部。点击“开始扫描”后显示枚举和内容比较进度；可取消扫描，切换离开扫描页也会请求取消尚在进行的扫描。

结果支持按路径/文件名筛选和多选。“智能选择”只改变当前可见结果的选择状态，不会立即删除：在每组可见重复文件中，优先保留平台提供的创建时间较早、路径层级较浅、路径较短的一份，最后按路径排序决定。

选择移除方式后点击“移除所选…”，确认窗口可滚动查看所有待处理的完整路径及操作方式。每组必须保留至少一份，选择整组会被拒绝。移除前会重新检查文件元数据、SHA-256 和与保留副本的逐字节一致性；已变化、丢失或无法读取的文件不继续处理。

## 判重与范围

- 原 WPF 实际使用 MD5 分组；新入口先按精确字节数找候选，再用 SHA-256 判重，不按文件名判断。
- 使用流式读取，每个读取块检查取消状态；进度约每 100 ms 更新，避免小文件过多时挤占 UI 队列。
- 支持不同目录之间的重复、嵌套/重复扫描路径去重及空文件。
- 单次最多 100,000 个匹配扩展名的文件，超过会失败并丢弃本次部分结果，应缩小目录或过滤范围。
- 不跟随目录/文件符号链接和 Windows 重解析点；扫描根目录及父路径含链接时拒绝，请选实际目录。macOS 的某些路径别名也可能因此被拒绝。
- 路径身份采用大小写无关及 Unicode NFC 的保守去重，避免把别名当成两份文件。在区分大小写/Unicode 形式的卷上，可能省略仅大小写/形式不同的独立路径；单独文件的此类冲突会记为跳过项。
- 访问拒绝、锁定、读取中变动等会记录跳过原因；内存最多保留 200 条详细原因，界面展示前 20 条。读不到的内容不会作为可删除重复项。
- Unix 打开文件使用非阻塞和不跟随最终链接的标志，不能定位的流会跳过，避免命名管道阻塞打开；该原生分支尚待 macOS/Linux 实测。

显示的重复字节数按路径估算，硬链接、文件系统压缩和回收站都会影响实际释放空间。没有全盘自动枚举、并行哈希、文件身份/硬链接专门识别、系统类型预设或精确剩余时间预测。

## 平台移除策略

| 平台 | 当前选项 | 行为 |
|---|---|---|
| Windows | 默认系统回收站；也可明确选择永久删除 | 通过原生接口显示系统确认/错误；代码不会在回收站失败后调用永久删除兜底 |
| macOS/Linux | 明确标注的永久删除 | 系统废纸篓/回收站未接入，回收站选项禁用；仍需确认完整路径 |

保留副本会在处理该组期间持有读取句柄。逐项记录结果，只从扫描列表中移除报告成功的路径；失败项保留。系统回收站操作取消时停止后续批次。文件移除不具备数据库事务式回滚，永久删除无法撤销；目录内容被外部程序并发替换时，校验与按路径调用系统操作之间仍有竞争窗口。请对稳定的文件集操作，文件变化时重新扫描。

Windows 的底层回收站最终行为依赖系统及卷类型，应以系统原生提示为准。当前自动化测试使用临时夹具和替代移除器，不操作用户文件或真实系统回收站；原生回收站交互属于平台验收。

## 扫描记录

完成的扫描自动保存所有匹配文件的路径、大小（兼容旧字段，单位 KiB）、时间和扫描目录。只有大小相同的候选做过哈希，因此 MD5 兼容字段对其他文件为空；不会把 SHA-256 写入名为 `Md5Value` 的旧列。

记录写入使用独立数据库作用域，一次 `SaveChanges` 提交。取消/扫描失败不保存部分记录；保存记录失败不抹掉已完成的当前结果，并显示保存失败原因。“加载记录”返回最近 500 条，包含可兼容的迁移旧记录，仅供查看；不从历史路径执行删除。移除文件后保留扫描历史，不把它当作当前文件状态。

## 验证边界

当前 Windows 环境验证了内容分组、扩展名、重叠目录、空文件、取消、锁定跳过、每组保留、变动/缺失副本保护、逐项错误、取消处理和历史持久化。窗口测试覆盖真实扫描→保存→智能选择→取消确认→确认移除，以及取消不发布结果、失败行保留和不可恢复删除提示。

符号链接测试因当前账户无法创建链接而跳过；macOS/Linux 原生文件打开、权限、链接和移除行为仍需实机验证。
